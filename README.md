# Classic Snake Game

Aplikasi game Snake klasik yang dikembangkan menggunakan Java Swing dengan antarmuka modern, kontrol yang responsif, dan performa yang ringkas.

---

## Overview

SnakeZ menghadirkan kembali pengalaman bermain game ular klasik dengan pembaruan visual yang bersih dan fitur tambahan:
- **Tampilan Modern**: Tema warna dark mode dengan aksen visual yang nyaman di mata.
- **Grid Interactive**: Latat belakang grid yang rapi untuk mempermudah navigasi.
- **Kontrol Fleksibel**: Mendukung tombol panah (Arrow Keys) dan tombol WASD.
- **Fitur Pause & Restart**: Tekan `P` untuk menjeda permainan dan `R` untuk memulai ulang.
- **Sistem High Score**: Mencatat skor tertinggi dalam sesi permainan.

---

## Teknologi

- **Bahasa Pemrograman**: Java (JDK 8+)
- **GUI Framework**: Java Swing & AWT
- **Build Tool**: Standalone Java Compiler (`javac`)

---

## Cara Menjalankan

### Prasyarat
Pastikan Java Development Kit (JDK) sudah terinstal dan terkonfigurasi di sistem Anda.

### Kompilasi & Eksekusi

1. **Clone Repositori**:
   ```bash
   git clone https://github.com/zoerlyx/snake-game-java.git
   cd snake-game-java
   ```

2. **Kompilasi Kode Program**:
    ```PowerShell
    com/zetcode/*.java
    ```
3. **Jalankan Game**:
    ```PowerShell
    java com.zetcode.Snake
    ```

### Kompilasi & Eksekusi 

- Gerak Atas      : Up Arrow / W
- Gerak Bawah     : Down Arrow / S
- Gerak Kiri      : Left Arrow / A
- Gerak Kanan     : Right Arrow / D
- Pause / Resume  : P
- Restart Game    : R
